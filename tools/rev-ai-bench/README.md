# Rev AI Benchmark Harness

Isolated benchmark tooling for evaluating local AI models. **No production code modified.**

## Purpose
Compare local models for Rev AI use cases: general assistance, browser automation, gaming.

## Usage
```bash
cd tools/rev-ai-bench
npm install
npm run build
npm run dev -- --help
```

## Restrictions
- No model downloads
- No production modifications
- No automatic cloud fallbacks
- Research only
